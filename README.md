# ✨ ANTIDEA - Institutional Website

> **Live Site:** [antidea.it](https://www.antidea.it/)  
> **Role:** Design Supervision & Frontend Development

ANTIDEA is an institutional project where my dual background in Brand Strategy and Development came together. Growing up in a high-level design environment, I approached this project not just as a coder, but as a **Design Supervisor**, ensuring that the final digital product maintained the aesthetic excellence required by the brand.

## 👁️ Design Supervision & Execution
* **Quality Gatekeeper:** I personally supervised the visual consistency, ensuring that every transition, margin, and typographic choice met premium design standards.
* **Pixel-Perfect Implementation:** My goal was to translate a high-level visual identity into a functional, high-performance website without compromising the original creative vision.
* **UX/UI Oversight:** I managed the user flow and interface logic, focusing on a seamless navigation experience that reflects the company's authority.

## 🛠 Tech Stack
* **Frontend:** HTML5, Modern CSS / SASS
* **Interactions:** JavaScript (ES6+)
* **Workflow:** Translating professional design mockups into clean, semantic code.
* **Future Implementation:** Currently planning the integration of a **WordPress CMS** to allow for dynamic content management.

## 🚀 Key Highlights
* **Performance & SEO:** A lightweight architecture that prioritizes speed and search engine visibility.
* **Responsiveness:** Meticulous adaptation for all screen sizes, maintaining the "premium feel" on mobile.
